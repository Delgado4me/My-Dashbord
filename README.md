# My-Dashbord

Особистий мобільний дашборд: Google Calendar, Gmail, справи дня, нагадування, нотатки, дні народження та читання Markdown із GitHub/Obsidian.

Цільове середовище — наявний проєкт Lovable. Бекенд — **існуючий зовнішній Supabase**. Нову базу Lovable Cloud не потрібно створювати, переносити таблиці чи користувачів не потрібно.

## Локальний запуск

```sh
python3 -m http.server 4173 --directory public
```

Відкрийте `http://localhost:4173`. Для живих інтеграцій використовуйте дозволену HTTPS-адресу застосунку. Серверні функції приймають лише явно налаштовані origins.

## Що підготовлено

- Видимий особистий вхід та форма зміни публічного URL/key Supabase у «Ще».
- У «Нотатки → Obsidian» — останні нотатки, фільтри, час перевірки, оновлення, окремі помилки й позначка часткового огляду.
- Після невдалого оновлення зберігається попередній список із позначкою його свіжості.
- Відновлено читання повного листа Gmail. Вихід із сесії захищений від запізнілого refresh; одночасні запити використовують одну спробу refresh.
- Налаштування сервера винесені в змінні середовища; дозволений один Auth-власник і одна Google-адреса. Репозиторій, гілка та папка нотаток налаштовуються окремо.
- Збережено компактний напрямок D11.1 і п’ять вкладок. D11.2–D11.4 не оголошуються завершеними цими змінами.

## Перевірки

Потрібен Node.js 22+:

```sh
node --test tests/auth-session.test.cjs tests/app-connections.test.cjs tests/backend-reconciliation.test.cjs tests/google-oauth-http.test.cjs tests/obsidian-http.test.cjs tests/reader-security.test.cjs tests/integration-config.test.cjs
```

Браузерна перевірка потребує Playwright та Chromium:

```sh
node tests/home-mobile.test.cjs
```

SQL-файли збережені як історія схеми. На вже працюючому Supabase **не виконуйте всі міграції повторно**: ці зміни не потребують зміни таблиць.
