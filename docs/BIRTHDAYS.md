# Дні народження: 5 → 3 → 0

30.09.2026 звірено 20 записів із наданого CSV з даними власника в наявному Supabase: імена, день, місяць і відомий рік уже збігаються. Повторний імпорт не виконувався. CSV та персональні імена не додаються у GitHub.

Нагадування всередині застосунку з’являються за 5 днів, за 3 дні та в сам день народження: у компактному «Сьогодні», календарі й розділі «Нагадування». На головній залишається ліміт 4 записи; решта доступна через «Весь день». Показ повторюється щороку автоматично з дати народження, без створення зайвих рядків у базі. Вимкнені дати не показуються. Для 29 лютого у невисокосний рік використовується 28 лютого.

Це нагадування в інтерфейсі під час користування застосунком; push та email-розсилку не налаштовано. Правило 5/3/0 є спільним для цього особистого дашборда. Старе поле `remind_days` залишене лише для сумісності схеми; актуальний UI використовує спільне правило. Окрему ручну справу «Привітати» можна створити з картки людини.

Перевірки охоплюють перехід року, 29 лютого, вимкнені дати, появу у розділах та відсутність дубля в календарі у сам день.
