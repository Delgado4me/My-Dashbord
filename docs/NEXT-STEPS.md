# Подальший план My-Dashbord
Оновлено: 01.10.2026. Робочий проєкт — Lovable; репозиторій коду — Delgado4me/My-Dashbord.

## Підтверджений стан
- Lovable завершив форму дня народження: день і місяць окремо, один необов’язковий рік; перевірки дат на синтетичних даних пройшли.
- У Lovable є кілька Google-пошт і виправлення перемикання джерел. Реальний OAuth і дві справжні скриньки ще потребують приймання.
- За попередньою перевіркою 20 днів народження скопійовано до підтвердженого входу; оригінали збережено. Не імпортувати повторно.
- Нагадування 5/3/0 — усередині застосунку, без push.
- GitHub відстає: перевірений public/app.js ще не містить нової форми й перемикача акаунтів.
- Жива dashboard-obsidian v5 має фіксований репозиторій і фіксованого власника. Це НЕ готове персональне підключення GitHub для нового входу.

## 1. Obsidian — поточний пріоритет
- [ ] GitHub App із мінімальними правами Contents: read та Metadata: read; дозвіл лише на вибрані користувачем репозиторії.
- [ ] «Нотатки → Obsidian → Підключити GitHub»: офіційна авторизація, повернення в застосунок, вибір доступного репозиторію, гілки та необов’язкової папки.
- [ ] Прив’язка інтеграції до автентифікованого власника дашборда; перевірка права на installation/repository на сервері, одноразовий state.
- [ ] Секрети й токени лише на сервері; не використовувати старий спільний токен для нового входу.
- [ ] Список папок, Markdown-читач, переходи між нотатками, фаворити з прив’язкою до джерела.
- [ ] Зміна/від’єднання джерела очищає старі дані; запізнілі відповіді не підміняють нові.
- [ ] Реєстрація GitHub App та безпечне встановлення серверних секретів. Без цього показувати чесний стан «не налаштовано», не імітувати успіх.
- [ ] Перевірити реальні нотатки в особистій сесії.

## 2. Зберегти актуальну версію
- [ ] Звірити й перенести потрібні зміни Lovable у GitHub, не перезаписуючи новіші сторонні зміни.
- [ ] Зберегти серверний код, тести й документацію; жодних приватних нотаток, CSV, токенів або особистих адрес у публічному репозиторії.
- [ ] Зафіксувати коміти, фактичні перевірки й залишки. Коміт не дорівнює розгортанню.

## 3. Доробити основні сценарії
- [ ] «У день» з листа → справа або нагадування з явним збереженням, без дублів та копіювання тіла листа.
- [ ] Категорії пошти: Основні / Оновлення / Промо / Соцмережі; повернення до фільтра й позиції.
- [ ] Звірити з кодом деталі подій, редагування нотаток, редагування/перенесення нагадувань і перехід до джерела.
- [ ] Компактна головна: до 4 записів дня, до 3 непрочитаних листів, доступ до повних списків. Старі дані фокусу зберегти.

## 4. Приймання

- [ ] Дні народження в поточному вході, 5/3/0, перехід року й 29 лютого.

AI та автоматичний пошук справ у листах, push, окремий Android APK. Не розширювати обсяг без потреби.
