# Початок

Це тестова нотатка My-Dashbord для перевірки читання Markdown із GitHub.

Після підключення джерела вона має з’явитися в «Нотатки → Obsidian → Додані». Змініть цей текст і збережіть commit: наступна перевірка повинна показати нову версію у «Змінені».

Особисті нотатки сюди не додавайте, поки репозиторій публічний. Приватний vault можна підключити окремо через серверний токен читання.
